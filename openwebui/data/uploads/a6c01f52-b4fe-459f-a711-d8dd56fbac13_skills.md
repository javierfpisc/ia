# 12. Material Design & MkDocs Visualization
[https://squidfunk.github.io/mkdocs-material/](https://squidfunk.github.io/mkdocs-material/) — Tema Material para MkDocs con soporte para admonitions, emoji, code highlighting, tabs, navegación mejorada y personalización CSS.

**Técnicas visuales recomendadas:**
- Admonitions con iconos: `!!! note`, `!!! warning`, `!!! tip`, `!!! example`
- Emojis contextuales: 📚 teoría, 🔧 práctica, 💡 tips, ✅ objetivos, ⚠️ advertencias
- Tablas con estilos y alineación
- Listas de tareas interactivas: `- [ ] Item`
- Tabs para alternativas: `=== "Opción 1"`
- Code highlighting con números de línea
- Breadcrumbs y navegación por tabs
- CSS personalizado para marca y accesibilidad
