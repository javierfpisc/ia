# Práctica: Despliegue de infraestructura con Vagrant

## Objetivo
El objetivo de esta práctica es desplegar un entorno de laboratorio compuesto por **tres nodos Debian** utilizando **Vagrant y VirtualBox**, simulando:

* Un clúster de Proxmox (en fases posteriores)
* Una red de gestión
* Una red interna para Ceph

## 1. Requisitos previos
Antes de comenzar, asegúrate de tener instalados:

* Motor de virtualización VirtualBox
* Vagrant
* Acceso a terminal

Verifica las versiones:

```bash
vagrant --version
VBoxManage --version
```

!!! warning "¡Cuidado!"
    Este procedimiento depende de la estabilidad de la versión de VirtualBox. Algunas versiones,
    como las 7.1.X dan problemas con la virtualización anidada. Si experimentáis algún problema al respecto recomiendo utilizar la versión 7.0.26

## 2. Estructura del entorno
El entorno se compone de 3 máquinas virtuales:

| Nodo | IP Gestión    | IP Ceph     | RAM  | CPU |
| ---- | ------------- | ----------- | ---- | --- |
| pve1 | 192.168.56.11 | 10.10.10.11 | 4 GB | 2   |
| pve2 | 192.168.56.12 | 10.10.10.12 | 4 GB | 2   |
| pve3 | 192.168.56.13 | 10.10.10.13 | 4 GB | 2   |

Cada nodo tendrá:

* Una interfaz de **gestión (red privada)**
* Una interfaz dedicada a **Ceph (red interna en el Provider utilizado)**


## 3. Creación del entorno

### 3.1 Ejecución del despliegue Vagrantfile
Usaremos para el despliegue el archivo `Vagrantfile` en el directorio **vagrant** para VirtualBox.

!!! warning "¡Ten en cuenta!"
    Antes de lanzar el siguiente procedimiento comprueba que hay disponible una interfaz de red en VirtualBox de tipo HostOnly con el direccionamiento definido en el rango 192.168.56.0/24, si no existe créala. 

### 3.2 Levantar las máquinas virtuales
Desde el directorio vagrant ejecuta el siguiente comando:
```bash
vagrant up
```
Este proceso:

* Descarga la imagen base `generic/debian12`
* Crea las 3 máquinas virtuales
* Configura redes y recursos
* Ejecuta el provisioning inicial

### 3.3 Agrupar las MVs
En VirtualBox cuando termine la ejecución del comando de despliegue agrupamos las 3 MVs bajo un grupo denominado **Despliegue**. Para ello ejecutamos (con las máquinas virtuales apagadas):
```bash
VBoxManage modifyvm pve1 --groups "/Despliegue"
VBoxManage modifyvm pve2 --groups "/Despliegue"
VBoxManage modifyvm pve3 --groups "/Despliegue"
```
El paso anterior es necesario para más adelante poder configurar el almacenamiento de Ceph.

## 4. Qué hace automáticamente el Vagrantfile
Durante el despliegue, se realizan varias acciones en cada nodo:

### Configuración de red

* Se asigna una IP de gestión en la red privada:

  * `192.168.56.0/24`
* Se crea una red interna para Ceph:

  * `10.10.10.0/24` (VirtualBox internal network: `ceph-net`)

### Configuración del sistema

* Instalación de paquetes básicos:

```bash
apt-get update
apt-get install -y curl wget gnupg2 sudo lsb-release ca-certificates
```

* Configuración del hostname:
    * pve1, pve2, pve3
* Configuración DNS:

```bash
echo "nameserver 8.8.8.8" > /etc/resolv.conf
```

### Acceso SSH
Se habilita el acceso como root:
```bash
PermitRootLogin yes
```
Esto facilita el trabajo en laboratorio.

### Resolución de nombres
Se configuran los nodos en `/etc/hosts`:

#### Red de gestión
```text
192.168.56.11 pve1
192.168.56.12 pve2
192.168.56.13 pve3
```

#### Red Ceph
```text
10.10.10.11 pve1-ceph
10.10.10.12 pve2-ceph
10.10.10.13 pve3-ceph
```

### Configuración de opciones de CPU virtual y red
Se habilitan opciones importantes:

* Virtualización anidada (nested virtualization)
* Modo promiscuo en red

Esto es necesario para ejecutar Proxmox dentro de las VMs en futuras prácticas.

## 5. Acceso a las máquinas
Una vez desplegado el entorno, puedes acceder a los nodos:

```bash
vagrant ssh pve1
vagrant ssh pve2
vagrant ssh pve3
```

## 6. Gestión del entorno

### Parar las máquinas
```bash
vagrant halt
```

### Destruir el entorno
```bash
vagrant destroy -f
```

### Reiniciar
```bash
vagrant reload
```

## 7. Comprobaciones
Una vez dentro de un nodo:

### Ver conectividad
```bash
ping 10.10.10.12
ping 192.168.56.12
```

### Ver interfaces de red
```bash
ip a
```

## 8. Resultado esperado
Al finalizar el despliegue:

* Los 3 nodos están activos
* Existe conectividad entre ellos
* La red de gestión y Ceph están separadas
* El entorno está listo para desplegar:
    * Proxmox
    * Ceph
    * Laboratorios de redes

## 9. Copia de seguridad de configuración vagrant
La configuración de vagrant reside en el directorio **vagrant/.vagrant**. Es recomendable crear una copia de seguridad del mismo para poder restaurar el estado del despliegue en caso de error o borrados accidentales. Una forma muy sencilla sería crear un archivo **.tar.gz** del directorio, una vez el despliegue vagrant está completo y funcional.

Podemos usar el comando: `tar czf vagrant-state-$(date +%Y%m%d).tar.gz .vagrant`
