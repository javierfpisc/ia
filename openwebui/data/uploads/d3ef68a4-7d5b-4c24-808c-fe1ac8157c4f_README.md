# Muestras de prácticas

Añade prácticas previas que sirvan como referencia de estilo, profundidad, estructura y formato. Incluye ejemplos de entregables o rúbricas solo si forman parte del modelo que quieres reproducir.

Las muestras no autorizan a copiar datos específicos ni a asumir que el entorno de una práctica antigua sigue vigente.
