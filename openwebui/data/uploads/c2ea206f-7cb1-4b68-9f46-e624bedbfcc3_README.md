# Materiales del módulo DPEC (Despliegue de plataformas de ejecución de contenedores)

Ficha del módulo. El sistema de producción, las instrucciones, las plantillas y los scripts son comunes y están en la guía de la raíz: [`../README.md`](../README.md). Las instrucciones del agente están en [`AGENTS.md`](AGENTS.md).

## Contenido específico

- **Unidades de contenidos:** `contenidos/unidades.yml`
- **Prácticas:** `practicas/unidades.yml`
- **Instrucciones propias:** `contenidos/instrucciones-modulo.txt` y `practicas/instrucciones-modulo.txt`
- **Fuentes por unidad:** `documentacion/`
- **Documentación oficial del módulo:** `modulo/`
- **Vista previa local:** `mkdocs/` (`docker compose up -d --build`, en `http://localhost:8888`)
- **Publicación:** `publicacion/repositorios.yml` y `publicacion/mkdocs.yml`
