# Vista previa local de los materiales (MkDocs)

Servicio Docker Compose que publica en local, en `http://localhost:8888`, los archivos `.md` de `contenidos/` y `practicas/`, con la jerarquía de carpetas como navegación.

## Uso

```bash
cd mkdocs
docker compose up -d --build   # primera vez o tras cambiar Dockerfile/mkdocs.yml
docker compose logs -f         # ver avisos de construcción
docker compose down            # parar el servicio
```

Los cambios en los `.md` se detectan y recargan en el navegador automáticamente. Las carpetas de origen se montan en solo lectura; el servicio no modifica el repositorio.

## Estructura

| Ruta en el contenedor | Origen en el repositorio | Modo |
|---|---|---|
| `/docs/contenidos` | `contenidos/` | solo lectura |
| `/docs/practicas` | `practicas/` | solo lectura |
| `/docs/modulo` | `modulo/` | solo lectura (para los enlaces a PDF/EPUB) |
| `/docs/index.md` | `mkdocs/docs-raiz/index.md` | solo lectura |
| `/docs/sistema.md` | `README.md` (guía del sistema de generación) | solo lectura |
| `/docs/.pages` | `mkdocs/docs-raiz/.pages` (orden del menú) | solo lectura |

La navegación la genera `mkdocs-awesome-pages-plugin` a partir de las carpetas. Los archivos que no sean `.md` no se publican como páginas; los que son enlazados, como el PDF y el EPUB de `modulo/`, se copian tal cual.
