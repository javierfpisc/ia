# Entorno de ejecución
El entorno para realizar las prácticas relacionadas con la presente unidad está basado en un pequeño clúster de 3 Máquinas Virtuales gestionadas con Vagrant.
Nuestro pequeño clúster de 3 nodos, suficiente para una ejecución mínima en modo laboratorio, constará de:

* **Un nodo Manager**: Ejecutando el Control Plane del clúster kubernetes
* **Dos nodos Workers**

## K3s
K3s es una distribución ligera de Kubernetes, desarrollada originalmente por Rancher (SUSE), diseñada para funcionar con pocos recursos y simplificar la instalación y administración de clusters. Sus principales características son:

* Ligero: consume muchos menos recursos que una instalación estándar de Kubernetes.
* Fácil de instalar: un único script permite levantar rápidamente un nodo.
* Menos componentes: integra y simplifica elementos que en Kubernetes convencional requieren más configuración.
* Adecuado para entornos pequeños: laboratorios, edge computing, IoT, desarrollo y clusters con hardware limitado.
* Compatible con Kubernetes: utiliza las APIs y herramientas habituales (kubectl, Helm, etc.), por lo que las aplicaciones Kubernetes estándar pueden ejecutarse en K3s.

En resumen: K3s es Kubernetes "simplificado y ligero", pensado para poder desplegar un cluster rápidamente sin necesitar tanta infraestructura ni configuración.

## Recursos
Los recursos necesarios para ejecutar el laboratorio están definidos en los correspondientes archivos de despliegue de Vagrant (Vagrantfile).
Usaremos una configuración de red mínima para no complicar de modo innecesario la infraestructura y que ésta no sea un obstáculo para el aprendizaje. Es por esto que dicha infraestructura dista mucho de ser óptima, es simplemente eso, un laboratorio de ejecución.
