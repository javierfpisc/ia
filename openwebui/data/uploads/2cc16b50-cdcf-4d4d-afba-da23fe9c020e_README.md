# Documentación del ciclo o módulo

Coloca aquí la documentación que define el contexto docente: programación didáctica, currículo, resultados de aprendizaje, criterios de evaluación, competencias, temporalización oficial u otros documentos propios del ciclo o módulo.

## Reglas
- Conserva los documentos originales.
- Indica claramente cuál es la versión vigente cuando existan varias.
- No guardes aquí las fuentes técnicas específicas de cada unidad; esas van en `documentacion/`.
- No añadas datos personales del alumnado.
- Si un documento contradice otro, no resuelvas la discrepancia silenciosamente: comunícala al profesor.
