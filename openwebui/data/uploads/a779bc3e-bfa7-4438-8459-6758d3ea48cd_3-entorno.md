# Entorno de ejecución para Proxmox
Nuestro entorno se ejecutará con 3 nodos sobre VirtualBox, corriendo como máquinas virtuales gestionadas con vagrant.

## Recursos
Cada nodo correrá con los recursos mínimos necesarios, siendo los requisitos mínimos (recogidos en el archivo vagrant/Vagrantfile):

- 2 vCPU  
- 4 GB RAM (ajustado pero suficiente)  
- Disco sistema
- Discos Ceph:  
    - 2 discos de 50 GB  

Por tanto los requisitos mínimos del equipo para ejecutar el laboratorio serán

- CPU moderna de mínimo 8 cores
- 16GB de memoria RAM
- 200 GB de espacio libre en disco

## Sistema operativo del host y dependencias

Se recomienda ejecutar como sistema operativo de base Debian en su versión estable con los siguientes paquetes y herramientas disponibles

- VirtualBox en versión reciente: [Descargar](https://www.virtualbox.org/wiki/Downloads)
- docker: [Instalación en Debian](https://docs.docker.com/engine/install/debian/)
- vagrant: [Instalación](https://developer.hashicorp.com/vagrant/install)
