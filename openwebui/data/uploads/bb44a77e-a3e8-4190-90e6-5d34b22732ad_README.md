# Fuentes de referencia

```text
documentacion/
└── unidad4-redes-seguras/       ← una carpeta por unidad
    ├── fuentes.yaml              ← URLs oficiales (prioritarias); plantilla en plantillas/fuentes.yaml
    └── manual.pdf                ← opcional: documentos locales (pdf, odt, docx, epub, md, txt, html)
```

- Prioridad: URLs oficiales de `fuentes.yaml` > documentos locales > muestras.
- Las URLs de `fuentes.yaml` quedan autorizadas; cualquier otra requiere aprobación.
- Cada apartado de `contenidos/unidades.yml` indica en `urls` qué URLs usa.
- Conserva los originales. No se guarda contenido generado aquí.
- Procesar un apartado: `python3 scripts/ingesta.py documentacion/<unidad> <apartado-id>`.
- Validar y depurar URLs: `python3 scripts/auditar_fuentes.py documentacion/<unidad>`.
