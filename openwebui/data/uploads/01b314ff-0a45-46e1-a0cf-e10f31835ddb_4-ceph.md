# Práctica: Despliegue de Ceph en un clúster Proxmox

## 1. Preparación inicial
Tras ejecutar:
```bash
vagrant up
```

Es necesario crear los discos que serán utilizados por los OSD de Ceph.
Se crearán dos discos por nodo.

## 2. Añadir discos a las máquinas virtuales

### 2.1 Apagar las máquinas
```bash
vagrant halt
```

### 2.2 Crear y adjuntar discos en VirtualBox
En **VirtualBox** necesitaremos ejecutar los pasos siguientes para añadir los discos virtuales para la configuración del almacenamiento distribuido con Ceph. 

Los discos se añaden a las VMs dentro del directorio **"Despliegue"**. Añadiremos 2 discos por nodo de 50GB. Ejecutar desde el host:
```bash
cat >> ceph-setup.sh <<'EOF'

# ============================================================
# Configuración de discos adicionales para Ceph
# ============================================================

read -r -p "¿Conectar los discos Ceph en pve1, pve2 y pve3? (s/N): " respuesta

if [[ "$respuesta" =~ ^[sS]([iI])?$ ]]; then

    for m in pve1 pve2 pve3; do
        echo "=== Configurando discos Ceph en $m ==="

        VM_DIR="$HOME/VirtualBox VMs/Despliegue/$m"

        if [[ ! -d "$VM_DIR" ]]; then
            echo "ERROR: No existe el directorio $VM_DIR"
            exit 1
        fi

        cd "$VM_DIR" || exit 1

        # Disco 1
        if [[ ! -f "ceph_${m}_disk1.vdi" ]]; then
            VBoxManage createmedium disk \
                --filename "$VM_DIR/ceph_${m}_disk1.vdi" \
                --size 50000 || exit 1
        fi

        VBoxManage storageattach "$m" \
            --storagectl "SATA Controller" \
            --port 1 --device 0 --type hdd \
            --medium "$VM_DIR/ceph_${m}_disk1.vdi" || exit 1

        # Disco 2
        if [[ ! -f "ceph_${m}_disk2.vdi" ]]; then
            VBoxManage createmedium disk \
                --filename "$VM_DIR/ceph_${m}_disk2.vdi" \
                --size 50000 || exit 1
        fi

        VBoxManage storageattach "$m" \
            --storagectl "SATA Controller" \
            --port 2 --device 0 --type hdd \
            --medium "$VM_DIR/ceph_${m}_disk2.vdi" || exit 1

        echo "Discos configurados correctamente en $m"
    done

    echo "Configuración de discos Ceph finalizada."

else
    echo "Operación cancelada por el usuario."
fi

EOF

chmod a+x ceph-setup.sh
./ceph-setup.sh
```

## 3. Inicialización de Ceph
Arrancamos de nuevo las máquinas con vagrant mediante el comando ```vagrant up``` y ejecutamos los siguientes pasos:

### En el nodo `pve1`
Como siempre accedemos al nodo mediante ```vagrant ssh pve1``` y una vez dentro ejecutamos (como root, usando sudo):
```bash
pveceph install
pveceph init --network 10.10.10.0/24
pveceph createmon
pveceph createmgr
```

- pveceph install → instala Ceph
- pveceph init → configura el cluster y la red
- pveceph createmon → crea el monitor
- pveceph createmgr → crea el manager


### En `pve2` y `pve3`
Análogamente en los otros nodos ejecutamos como root
```bash
pveceph install
pveceph createmon
```

### Verificación del estado
```bash
pveceph status
```

## 4. Creación de OSDs
Ejecutar desde el directorio **vagrant:**
```bash
for node in pve1 pve2 pve3; do
  vagrant ssh $node -c "sudo pveceph osd create /dev/sdb"
  vagrant ssh $node -c "sudo pveceph osd create /dev/sdc"
done
```

El comando anterior creará los OSDs de ceph correspondientes a los discos añadidos

### Verificación
```bash
pveceph status
```

## 5. Creación del Pool
Desde el nodo pve1, ejecutamos como root (todos los comandos de administración de Ceph se ejecutarán como root):
```bash
ceph osd pool create labpool 128
```

> El número (128) corresponde a los Placement Groups (PGs), que distribuyen las escrituras.


### Configuración del pool
```bash
ceph osd pool set labpool size 3
ceph osd pool set labpool min_size 2
```

### Activar soporte RBD
```bash
ceph osd pool application enable labpool rbd
```

## 6. Integración del almacenamiento en Proxmox
Añadir el almacenamiento RBD al clúster:

```bash
pvesm add rbd ceph-rbd --pool labpool --content images,rootdir \
--krbd 0 --monhost 10.10.10.11,10.10.10.12,10.10.10.13
```

!!! warning "¡Crear snapshots de las máquinas!"
    Es un buen momento para crear otra snapshot de las MVs de VirtualBox con la configuración de Ceph completa
    ```
    for vm in pve1 pve2 pve3; do
        VBoxManage snapshot "$vm" take "cluster-ceph-creado"
    done
    ```   

## Resultado
Tras estos pasos:

* El clúster Ceph está operativo
* Los OSDs están distribuidos en los nodos
* El pool permite replicación de datos
* Proxmox puede usar Ceph como almacenamiento distribuido
* Se habilita alta disponibilidad y migración en vivo
