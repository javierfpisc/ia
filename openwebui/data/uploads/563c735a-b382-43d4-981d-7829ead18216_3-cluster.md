# Pŕactica: Creación del clúster Proxmox
Nuestro cluster estará formado por los 3 nodos corriendo como MVs VirtualBox gestionadas con vagrant.

## 1. Creación cluster
En pve1 ejecutamos:
```bash
sudo -i
pvecm create lab-cluster
```

## 2. Añadiendo nodos al cluster
En pve2 y pve3 ejecutamos:
```bash
sudo -i
pvecm add 192.168.56.11
```

El anterior comando de adhesión nos pedirá la password de root del nodo pve1 que inició el cluster. Verificamos con:
```bash
pvecm status
```

!!! warning "¡Haz una snapshot!"
    Sería recomendable después del proceso de creación de los nodos y su adhesión al cluster que realizaras una instantánea (snapshot) del estado de cada una de las Máquinas del cluster en VirtualBox. Puedes hacerlo con el comando:
    ```
    for vm in pve1 pve2 pve3; do
        VBoxManage snapshot "$vm" take "cluster-proxmox-creado"
    done
    ```
